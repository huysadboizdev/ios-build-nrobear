# NRO — PC và Android

- Windows: giải nén `NRO-Windows-x64.zip`, giữ nguyên toàn bộ thư mục `Windows`, chạy `NRO.exe`.
- Android: cài `Android/NRO.apk`. Ứng dụng chạy ngang màn hình, có ARMv7 và ARM64.
- Server native: `160.191.245.239:14445`.
- Icon Vegeta tóc tím lấy từ bản 3 in 1.
- Hào quang đen hiện từ 70 tỉ sức mạnh cho nhân vật mình và đệ tử có dữ liệu sức mạnh, ở cả hai tài khoản. Điều khiển bằng tùy chọn Hào quang sức mạnh đang có.
- Android hiện dùng khóa ký phát triển của Unity; xem `Android/signing.txt`.

Bản web tương ứng được cập nhật trong `ClientWeb/PRJ_2Tab_Web/Builds/WebGL`, truy cập qua gateway hiện có tại `localhost:8086` và tải lại bằng Ctrl + F5.

Kiểm tra build, icon, cấu hình APK và hồi quy đã có log; chưa kiểm thử cài APK trên thiết bị Android thật trong lần dựng này.
